# NPTEL Industry 4.0 & IIoT Practice Quiz

An interactive, self-contained web application featuring practice questions for the NPTEL exam on **Introduction to Industry 4.0 and Industrial Internet of Things (IIoT)**. It covers Assignments 1 through 12 (180 questions) with instant scoring, tabbed navigation, and success alerts.

## 👨‍💻 Author
* **Prepared by:** Surya S (AI&DS)

## ✨ Features
* **Complete Coverage:** Includes Assignments 1 to 12 (15 questions per assignment).
* **Interactive UI:** Clean, modern tabbed interface to easily switch between different assignments.
* **Instant Feedback & Scoring:** View your live tracking score and submit assignments to see correct answers instantly.
* **Success Celebrations:** Special congratulatory alerts when you achieve a perfect score of 15/15!
* **Zero Dependencies:** Built using standard HTML, CSS, and vanilla JavaScript—fully self-contained in a single file.
